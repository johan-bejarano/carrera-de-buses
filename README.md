
# Carrera de Buses versión Transmilenio F19 VS H15 

## 📌 Descripción

Carrera de Buses es un proyecto desarrollado en Python que simula una competencia entre dos buses articulados mediante una representación visual en la consola.

El programa permite visualizar el desplazamiento de los buses a lo largo de una pista hasta alcanzar la línea de meta, generando una experiencia sencilla de competencia mediante animaciones en consola.

## ⚙️ Tecnologías utilizadas

- **Python:** lenguaje de programación utilizado para desarrollar la simulación.
- **Time:** gestión de los intervalos de tiempo para controlar la animación.
- **OS:** interacción con la consola y actualización de la presentación.
- **Random:** generación de elementos aleatorios para la dinámica de la carrera.

## 🚦 Características principales

- Representación visual de buses articulados mediante caracteres de texto.
- Simulación del desplazamiento de los buses.
- Visualización de una pista de carrera.
- Identificación de la línea de meta.
- Presentación de la competencia directamente en la consola.

## ▶️ Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Tener Python instalado en el computador.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar el siguiente comando:

```bash
python "carrera de buses.py"
```
